O **Synarchy** é um framework focado em metodologia, projetado pela **Hibex Solutions** para governar a interação entre Arquitetos Humanos e Agentes de IA. Ele vai além do "código assistido" para estabelecer um protocolo estruturado de soberania compartilhada.

Não é uma ferramenta para construir agentes; é um **sistema de governança** para construir softwares de alta qualidade através deles.

---

## 📖 A Filosofia: Governança Conjunta

Na era da engenharia de software orientada a IA, acreditamos que construir sistemas complexos exige um novo contrato social. O **Synarchy Framework** estabelece que:

*   **A Regra 80/20:** Agentes de IA são responsáveis pelo "trabalho pesado" (80%) da geração de código.
*   **A Soberania:** O Arquiteto Humano detém a responsabilidade final pelos **20% cruciais** que definem a segurança, a lógica de negócio e a integridade arquitetural.
*   **Fluxos Normativos:** Todo o desenvolvimento segue um protocolo estrito de papéis predefinidos e estruturas de diretórios para evitar o desvio arquitetural (*architectural drift*).

Para mais detalhes sobre o nome e sua origem, consulte o arquivo [NAMING_pt-BR.md](NAMING_pt-BR.md).

## 🚀 Conceitos Chave

*   **O Arquiteto (Humano):** A autoridade soberana que valida, governa e exerce o poder de veto sobre todas as propostas geradas por IA.
*   **Os Agentes (IA):** Entidades especializadas que operam sob regras estritas dentro de um ambiente padronizado (ex: o diretório `.agents/`).
*   **O Protocolo:** Um conjunto de arquivos base e fluxos de trabalho obrigatórios que garantem que o software permaneça arquiteturalmente íntegro, independentemente de qual entidade manipulou o código por último.
